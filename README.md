 # MathorCup D题 — 三维装箱优化
 
 ## 概述
 
 2025年MathorCup高校数学建模挑战赛 D题求解方案：针对5类货物（标准件、易碎件、定向件）和2种车型，设计遗传算法实现三维装箱优化，满足承重约束、支撑约束、朝向约束，并支持多目标优化（容积率×重量率）。
 
 ## 求解问题
 
 | 问题 | 说明 |
 |---|---|
 | 问题一 | 单车型最少车辆数（V1/V2） |
 | 问题二 | 多车型组合调度（成本最小化） |
 | 灵敏度分析 | 规模倍率对装载率的影响 |
 | 附件二验证 | 8种标准车型配置验证 |
 | 多目标优化 | 单车容积×重量乘积最大化 |
 
 ## 项目结构
 
 | 文件 | 用途 |
 |---|---|
 | `Mathor_Cup_D_solution.cpp` | 核心求解器 — 基于遗传算法的三维装箱 |
 | `Visualization1.py` | 可视化 — 柱状图、饼图、堆积高度热力图 |
 | `problem1_placement.txt` | 输出结果 — 每辆车每件货物的精确放置坐标 |
 
 ## 求解器架构
 
 - **遗传算法**：种群迭代优化，支持交叉、变异、精英保留
 - **放置引擎**：基于层（shelf）的贪心填充，枚举货物朝向，检查支撑与压强
 - **约束处理**：易碎件仅放置于顶层（无支撑），定向件固定朝向，标准件自由旋转
 - **多目标模式**：四种优化目标 — `VOLUME`（容积率）、`WEIGHT`（重量率）、`SUM`（和）、`PRODUCT`（乘积）
 
 ## 使用方法
 
 ```bash
 # 编译并运行 C++ 求解器
 g++ -std=c++17 -O2 -o solver Mathor_Cup_D_solution.cpp && ./solver
 
 # 生成可视化图表（需安装 matplotlib, numpy）
 python3 Visualization1.py
 ```
